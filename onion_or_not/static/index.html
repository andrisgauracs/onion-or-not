    How does this work?

    Every model gets the same question about the headline text only: “Is this headline satire from The Onion, or real news?” with the options satire and real news. The bars show each model's probability for each option.

    Jev is TypeSafe's hosted decision model. It runs in the cloud with your own TypeSafe API key and costs a fraction of a cent per question.

    AnyJev L0 runs Qwen3-8B on your own computer through llama.cpp and reads its answer with AnyJev. Level L0 asks with the options in every order and removes the model's built-in lean toward one option, so swapping the options can't change its answer.

    Qwen3-8B raw is the same model on your computer with no correction, so you can see what AnyJev changes.
